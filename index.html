Tip: Import into a new calendar

We recommend creating a new calendar for this schedule.
If you ever need to remove it, you can delete the entire calendar instantly, rather than deleting each event one by one.

  1. Download the .ics file using the button below.
  2. In Google Calendar, go to Settings ⚙️ → Add calendar → Create new calendar (e.g. name it Quran Plan).
  3. Go to Import & export → Import, select the downloaded file, and choose your Quran Plan calendar.
